Operator precedence dictates the order of operations. Parentheses `()` are evaluated first, followed by unary plus/minus, exponentiation, multiplication/division, addition/subtraction, concatenation, coercion, comparison, and finally logical operators.

### Operators Reference

Source: https://developer.apple.com/library/archive/documentation/AppleScript/Conceptual/AppleScriptLangGuide/reference/ASLR_operators.html

AppleScript provides logical and mathematical operators, as well as operators for containment, concatenation, and obtaining a reference to an object. Operators that operate on two values are called binary operators, while operators that operate on a single value are known as unary operators.

--------------------------------

### Operators

Source: https://developer.apple.com/library/archive/documentation/AppleScript/Conceptual/AppleScriptLangGuide/conceptual/ASLR_lexical_conventions.html

An operator is a symbol, word, or phrase that derives a value from another value or pair of values. Examples include the multiplication operator (*) for numbers and the concatenation operator (&) for joining objects like text strings. The `is equal` operator tests Boolean values.

--------------------------------

### Operators

Source: https://developer.apple.com/library/archive/documentation/AppleScript/Conceptual/AppleScriptLangGuide/reference/ASLR_classes.html

Text objects can be used as operands with several operators, including `&`, `=`, `≠`, `>`, `≥`, `<`, `≤`, `starts with`, `ends with`, `contains`, `is contained by`, and `as`. Text comparisons can optionally consider or ignore whitespace.

Several operators can be used with list values, including concatenation (`&`), equality comparison (`=`, `≠`), and membership testing (`starts with`, `ends with`, `contains`, `is contained by`).
